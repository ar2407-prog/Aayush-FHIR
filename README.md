## ✨ Overview

**AyushFhir** is an advanced health-tech platform designed to harmonize traditional Indian medicine systems (Ayurveda) with global interoperability standards. By bridging the WHO International Classification of Diseases (ICD) with NAMASTE (National AYUSH Morbidity and Standardized Terminologies Electronic) codes, the platform enables seamless integration between traditional clinical insights and modern electronic health record (EHR) systems.

Powered by modern web technologies and robust AI pipelines, AyushFhir bridges the gap between patient consultations and clinician oversight through intelligent chat agents, automated R4 FHIR generation, and context-aware dietary engines.

---

## 🚀 Key Features

### 🗺️ ICD & NAMASTE Code Mapping Engine
* **WHO ICD-11 & ICD Integration:** Advanced relational and vector mapping between standard global diagnostic terminology and traditional Ayurveda NAMASTE classifications.
* **Specialized Ayurveda Modules:** Dedicated exploration pages for exploring ICD-11 codes mapped directly to traditional terminologies.

### 🩺 Advanced Doctor Dashboard & FHIR R4 Generation
* **Clinical Report Generation:** Allows practitioners to create detailed patient evaluations.
* **Vector-Assisted Intelligence:** Leverages vector mapping to link clinical notes with precise diagnostic codes.
* **HL7 FHIR R4 Standard Compliance:** Automatically compiles consultation data into standardized R4 FHIR resources for universal interoperability.

### 🥗 Intelligent Diet & Nutrition Engine
* **Personalized Recommendations:** Generates specific dietary guidelines based on diagnosed conditions and traditional classifications (*Aahar*).
* **Dietary Dos and Don'ts:** Clear, actionable guidance tailored to patient health metrics and constitutional types.

### 🤖 Patient Dashboard & AI Doctor Consultation
* **Interactive AI Chat:** Patients can interact with an AI-powered medical assistant to discuss symptoms, medical history, and daily health concerns.
* **Automated Clinical Handover:** The AI agent structures the conversation into a comprehensive summary report that feeds directly into the real doctor's clinical dashboard for review.

## 🛠️ Technology Stack

* **Backend:** Python, FastAPI, `uv` (Fast Python package installer and resolver)
* **Frontend:** Jinja2 Templates, HTML5, Tailwind CSS
* **Database & Auth:** Supabase (PostgreSQL & Realtime)
* **Interoperability Standard:** HL7 FHIR R4
